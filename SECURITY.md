# Security policy

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/stuckinowhere/fast-torrent-download/security/advisories/new). Include the affected version, impact, and minimal reproduction details. Do not open a public issue for an undisclosed vulnerability.

You should receive an initial response within seven days. Confirmed issues will be coordinated through a security advisory before public disclosure.

## Scope

Reports should demonstrate an impact across a trust boundary. Generic hardening suggestions, self-inflicted local changes, and behavior that requires downloading untrusted content by choice are not treated as vulnerabilities without a concrete security impact.
